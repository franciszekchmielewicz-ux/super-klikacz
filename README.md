# 🪙 SUPER KLIKACZ - WERSJA 1.0

Witaj w **Super Klikaczu**! Jest to pierwsza, klasyczna wersja tekstowej gry klikanej (Clicker Game), stworzona w całości przy użyciu czystego kodu HTML, CSS i JavaScript. 

Projekt powstał z myślą o prostocie, płynności działania oraz uruchamianiu bezpośrednio w oknie przeglądarki – bez konieczności pobierania jakichkolwiek plików na dysk!

## 🚀 Zagraj Teraz
Gra jest w 100% darmowa i działa ogólnie na komputerach Kliknij w poniższy link, aby zacząć zarabiać złoto:
👉 **[https://github.com/franciszekchmielewicz-ux/super-klikacz]**

---

## 🎮 Funkcje Wersji 1.0
* **Cyanowo-Czarna Estetyka:** Elegancka, minimalistyczna oprawa wizualna w stylu retro.
* **Główny Licznik:** Precyzyjne naliczanie zdobytego złota oraz podgląd aktualnej siły kliknięcia.
* **Sklep z Ulepszeniami:** Możliwość zakupu lepszego kliku – każde ulepszenie stale zwiększa liczbę punktów zdobywanych za jedno tąpnięcie.
* **Efekty Dźwiękowe:** Wbudowane, klasyczne 8-bitowe piknięcia przy klikaniu oraz podwójny dźwięk sukcesu podczas zakupów w sklepie.

---

## 🛠️ Technologie
* **HTML5** - szkielet gry i struktura interfejsu.
* **CSS3** - ciemna stylistyka wizualna i złote ramki.
* **JavaScript** - logika gry, obsługa matematyki sklepu oraz generowanie dźwięków przez *Web Audio API*.
